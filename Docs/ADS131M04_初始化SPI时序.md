# ADS131M04 初始化阶段 SPI 时序全记录（逐帧）

版本：v1.0　|　日期：2026-08-21　|　对应固件：`App/bsp/ads131m04.c`（Step 1 驱动）

本文档逐帧列出初始化阶段（`ADS131M04_Init` 内）MCU 发出的全部 SPI 数据与芯片的预计回读内容，供逻辑分析仪/示波器/调试缓冲核对。**当前失败点：第 6 帧（MODE 回读）期望 `05 10 00`，实测 `00 00 00`。**

---

## 1. 约定

- **一帧 = 6 字 × 24bit = 144 个 SCLK**，CS 低电平恰好覆盖整帧；CS 拉高复位接口（DOUT 三态）
- **全双工流水线**：帧 N 的 MOSI = MCU 发的命令；帧 N 的 MISO = 芯片对**帧 N-1 命令**的响应（延迟一帧）
- **字节序**：MSB 先行；每 24bit 字 = 3 字节（高字节在前）
- 16 位寄存器值在 24bit 字中 **MSB 对齐**（低 8 位为 0），如 MODE=0x0510 → 字 = `05 10 00`
- SCLK：**5MHz（presc=16，一帧 28.8µs，每字节 1.6µs）**——5MHz 决策：tp(SCDO) 最坏 50ns，采样点 100ns = 100% 余量（10MHz 恰在规格线上，实测回读不稳定）；速率不影响帧内容，只影响时钟宽度
- 4 通道转换数据（ch0~ch3）内容取决于前端实际输入，**不在本文档预测范围内**，表中以 `ch0`~`ch3` 标记

## 2. 命令字编码（16 位命令 → 24bit 字 = 命令<<8）


| 命令       | 编码                   | 说明                                       |
| ------------ | ------------------------ | -------------------------------------------- |
| NULL       | 0x0000                 | 无操作；芯片默认响应 STATUS+4 通道数据     |
| UNLOCK     | 0x0655                 | 解锁接口                                   |
| LOCK       | 0x0555                 | 锁定接口（锁定后仅 NULL/RREG/UNLOCK 有效） |
| WREG(addr) | `0x6000 | addr<<7 | 0` | 写 addr 起的 1 个寄存器                    |
| RREG(addr) | `0xA000 | addr<<7 | 0` | 读 addr 起的 1 个寄存器                    |

## 3. 芯片响应规则（MISO 内容预测依据）


| 上一帧命令               | 本帧 MISO 字 0                                 | 字节示例                 |
| -------------------------- | ------------------------------------------------ | -------------------------- |
| 无（复位后第一帧）/ NULL | STATUS 寄存器（0x0500）+ ch0~ch3 + CRC 字（0） | `05 00 00`               |
| UNLOCK                   | 命令回显 0x0655                                | `06 55 00`               |
| LOCK                     | 命令回显 0x0555                                | `05 55 00`               |
| WREG(addr)               | 写入计数回显 =`0x4000 | addr<<7 | 0`           | addr=0x02 →`41 00 00`   |
| RREG(addr)               | 寄存器值（16 位 MSB 对齐）                     | MODE=0x0510 →`05 10 00` |

## 8. 校验点清单（按此顺序核对）

1. 帧 2 MISO 字0 = `06 55 00` → 芯片正确解码 UNLOCK，响应流水线正常
2. 帧 4 MISO 字0 = `41 00 00` → 芯片正确解码 WREG（写侧正常）
3. 帧 6 MISO 字0 = `05 10 00` → 回读正常，初始化应继续
4. 帧 120 MISO 字0 = `24 xx 00` → ID 正确，`s_init_stage` 将到 9

**判读**：

- ②正常④正常⑥全 0 → 流水线正常、RREG 响应帧内容丢失 → 时序/采样点问题（降速验证）
- ②就全 0 → 芯片从未正确响应（DOUT 未驱动有效数据）
- ⑥=`05 00 00`（STATUS 而非寄存器值）→ 响应错位一帧（RREG 未被解码）
- 全部正常 → 初始化通过，进入流采集（方案 A：DRDY 下降沿 → DMA → K=32 环形缓冲）

## 9. 流采集帧完整拆分（每个采样周期 1 帧）

**速率**：fDATA = 3.906kHz（帧周期 256µs）｜SCLK 5MHz（每帧 144 时钟 = 28.8µs，占周期 11.3%）
**触发**：DRDY 下降沿 → EXTI ISR → CS 拉低 → TX/RX DMA 18 字节 → CS 拉高（方案 A）
**MCU 发出（DIN）**：NULL 命令 + 5 个全零字（共 18 字节全 0）
**芯片回发（DOUT）**：STATUS + 4 通道数据 + CRC 字（响应流水线：本帧内容 = 对上一帧命令的响应）

### 9.1 字节/字布局


| 字节偏移 | 字        | 内容                                                                      | 位级结构                            |
| ---------- | ----------- | --------------------------------------------------------------------------- | ------------------------------------- |
| 0~2      | **word0** | **STATUS 寄存器**（16 位有效值，MSB 对齐于 24bit 字的 bit23:8，bit7:0=0） | 见 9.2                              |
| 3~5      | **word1** | **CH0 转换数据**（24bit 二进制补码）                                      | 1 LSB = +FSR/2^23，FSR=±1.2V/GAIN1 |
| 6~8      | **word2** | **CH1 转换数据**                                                          | 同上                                |
| 9~11     | **word3** | **CH2 转换数据**                                                          | 同上                                |
| 12~14    | **word4** | **CH3 转换数据**                                                          | 同上                                |
| 15~17    | **word5** | **CRC 字**（RX_CRC_EN=关闭 → **恒 0x000000**）                           | —                                  |

每字 3 字节按 **MSB 先行**（字节顺序：高、中、低）。

### 9.2 word0（STATUS）位级拆分


| 位（16 位值内） | 字段     | 含义                                                      |
| ----------------- | ---------- | ----------------------------------------------------------- |
| 15              | LOCK     | 接口锁定标志                                              |
| 14              | F_RESYNC | 同步故障标志                                              |
| 13              | REG_MAP  | 寄存器表 CRC 变化标志                                     |
| 12              | CRC_ERR  | 输入 CRC 错误标志                                         |
| 11              | CRC_TYPE | CRC 类型（0=CCITT-16）                                    |
| 10              | RESET    | 复位发生标志（本板芯片清不掉，恒 1，信息性）              |
| 9:8             | WLENGTH  | 字长（00=16bit/01=24bit/10=32bit 补零/11=32bit 符号扩展） |
| 3:0             | DRDY3:0  | 各通道新数据就绪标志（读走整帧后清除）                    |

### 9.3 固件解析（App/bsp/ads131m04.c ReadFrame）

```
status_word = 字节 0~2 合成（GetWord）        → f->status
status16    = status_word >> 8                → 健康位检查
ch[i]       = 字节 (3+3i)~(5+3i) 合成 24bit  → 符号扩展（|0xFF000000 若 bit23=1）
             → 按 ADC_CH_SIGN_MASK 逐通道取反 → f->ch[0..3]
tick_ms     = HAL_GetTick()
```

### 9.4 运行时观测变量（调试器）


| 变量                    | 内容                      | 结构判据                                   |
| ------------------------- | --------------------------- | -------------------------------------------- |
| `s_frame_w[0..5]`       | 最新一帧 6 个原始字       | word5 应恒 0（CRC 关）；word1~4 应缓慢漂移 |
| `s_frame_status`        | 解析出的 STATUS 16 位值   | 帧间应恒定                                 |
| `s_last_frame.ch[0..3]` | 解析后的通道数据（int32） | DC + 噪声                                  |
| `s_diag.frames_read`    | 消费帧计数                | 3906/s                                     |

### 9.5 数据字解读

- 24bit 补码 → int32：`v = raw; if (raw & 0x800000) v |= 0xFF000000;`
- 电压换算：`V = v × 1.2 / (GAIN1 × 2^23)`（GAIN1=1 时 1 LSB ≈ 0.143µV）
- 本板前端为"放大器输出 − BIAS1_OUT"差分，静态值即直流偏置差（预期为大 DC 值，非 0）

## 10. 调试历程总结（2026-08-21，Step 1 bring-up 全记录）

### 10.1 问题与解决（按时间顺序，共 13 项）


| #  | 症状                                                         | 根因                                                                                           | 解决                                                                                                         |
| ---- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 1  | 两个指示灯恒高不闪                                           | TIM2 只 Init 未 Start（CubeMX 不负责启动）                                                     | `HAL_TIM_Base_Start_IT(&htim2)`                                                                              |
| 2  | LED 语义与文档相反                                           | 板载 LED 为**高电平点亮**（非文档假设的灌电流）                                                | 代码/文档极性全面修正                                                                                        |
| 3  | MISO/DRDY 完全无输出、VCAP=0V                                | **旧芯片内部 LDO 损坏**                                                                        | 更换芯片（换后 VCAP 正常）                                                                                   |
| 4  | CS/DRDY 观测混乱                                             | **物理接线与原理图相反**                                                                       | CubeMX 对调（PA15=DRDY EXTI、PC14=CS），确立"以 CubeMX 为准"原则                                             |
| 5  | 回读值不稳定（每次复位不同）                                 | SCLK 20MHz 下采样点 25ns < tp(SCDO) 最坏 50ns                                                  | **速率定 5MHz**（采样点 100ns = 100% 余量；10MHz 恰在规格线上仍不稳）                                        |
| 6  | 初始化后 DRDY 计数恒 0                                       | **DRDY 电平式死锁**：复位后 DRDY 已拉低，下降沿永不出现                                        | `Ads_ResumeStream` 开流时若 DRDY 已低则"踢一脚"补读                                                          |
| 7  | 复位脉冲时序隐患                                             | 1ms 脉冲超出 8~2048 tCLKIN 复位窗口（会被解释为"同步"）                                        | 12.5µs 忙等待脉冲                                                                                           |
| 8  | WREG 回读失败、流数据错位（CRC 位非零、STATUS 丢失）         | **REVID=0x05 芯片寄存器布局与 SBAS890D（REV A）不同**：写 MODE（旧布局值）把字长清成 16 位模式 | 见 10.2 最终策略                                                                                             |
| 9  | 芯片带着坏状态跨 MCU 复位持续运行                            | SYNC 引脚复位不可依赖                                                                          | **自愈序列**：UNLOCK→NULL→RESET→NULL（"命令+NULL"两拍在 16 位坏模式下命令槽仍自对齐，LCM(144,96)=288 位） |
| 10 | STATUS.RESET 标志恒置位导致 spi_err 每帧 +1                  | 本芯片清不掉 RESET 标志                                                                        | 该位改为信息性标志`s_st_reset_flag`，不计错误                                                                |
| 11 | 0x3F（RESERVED）回读校验必失败                               | 手册只要求"恒写 0"、未定义回读值                                                               | 只写不校验                                                                                                   |
| 12 | 分析仪解码与 MCU 实测矛盾（MOSI 数据字"移位"、响应字"丢失"） | 逻辑分析仪 SPI 解码器在临界时序下位失步，产生伪影                                              | **以 MCU 侧硬件采样为准**（s_init_rx 缓冲/s_frame_w 观测点），分析仪仅作参考                                 |
| 13 | 探针验证后仍停第五步                                         | 只读验证重写时误用过期局部变量`id`                                                             | 改用`s_chip_id`                                                                                              |

### 10.2 最终初始化策略（REVID=0x05 芯片）

```
CS 高 → DRDY EXTI 重配（下降沿）→ CLKIN 8MHz 启动
→ PC15 复位脉冲 12.5µs → 等 DRDY 上升沿（100ms 超时）
→ 自愈序列：UNLOCK → NULL → RESET → NULL → 重新等 DRDY 上升沿
→ UNLOCK
→ 探针读回：ID（期望 0x24xx）/ MODE（期望 0x0510）/ CLOCK（期望 0x0F0E）
→ 校验通过 → 开流采集（丢弃 2 帧）
【不写入任何寄存器、不 LOCK——本芯片复位默认值即目标配置，写入会破坏（见 #8）】
```

### 10.3 经验教训

1. **分析仪解码≠总线真相**：SPI 解码器在临界时序下会产生系统性位滑移伪影；固件侧硬件采样（环形缓冲 + 标量导出）才是权威判据。调试顺序应为：MCU 观测点 → 示波器（电平/边沿） → 分析仪（协议参考）。
2. **新硅片 ≠ 旧手册**：REVID 与数据手册版本必须匹配（ID=0x2405 的芯片与 SBAS890D 的寄存器布局存在差异）。写入任何寄存器前先回读验证默认值；"全部显式写一遍"的策略在布局未确认的芯片上是危险的。
3. **电平式 DRDY + 下降沿 EXTI 的死锁模式**：复位/暂停后必须检查引脚电平并补触发，这是 ΔΣ ADC 驱动的经典陷阱。
4. **调试器复位 ≠ 外设复位**：ADC 状态跨 MCU 复位持续存在，需要芯片级复位（POR/引脚/RESET 命令）兜底。
5. **复位脉冲宽度是窗口不是下限**：SYNC/RESET 双功能脚的 8~2048 tCLKIN 窗口内是复位、超过是同步——"越长越好"不成立。
6. **时序规格要按最坏值设计**：tp(SCDO)=50ns 是 20pF 负载下的最坏值，SCLK 采样点必须留余量（本板定 5MHz，100ns 采样点 = 2 倍余量）。
7. **调试变量要"标量化 + 可 watch"**：Ozone CSV 导不出数组内容，逐项标量（s_init_rx_w0[n]、s_frame_w[n]、s_st_*）才是可导出的调试资产。
